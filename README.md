# 当前时间组件

打开 `index.html` 即可预览实时效果：大号黑色时分秒，下方为中文日期和星期。

- 固定显示北京时间（Asia/Shanghai），每秒刷新，页面从后台恢复时立即校准。
- 时间来源为设备时钟；设备时刻不准会影响显示。
- 随窗口宽度调整字号；背景透明，适合放进浅色容器。
- 不显示倒计时、按钮或其他文字；不读取表格数据。
- 本地预览无需账号、安装依赖或联网。

## GitHub 与网页地址

仓库根目录的 `index.html` 是时钟页面入口。GitHub 的源码页面地址不能作为飞书插件服务地址。

已发布的时钟页面：**https://duuhuang-ai.github.io/feishu-clock/**

飞书的自定义插件「服务地址」应填写上面这个网页地址。

需要托管为网页时，可在仓库 Settings → Pages 选择 Deploy from a branch，再选择 `main` 分支的根目录 `/ (root)`。账号套餐、仓库可见性须支持 Pages。仅上传代码不会自动发布网站，实际网址以 Pages 部署结果为准。

## 飞书接入状态

时钟网页已通过 GitHub Pages 公开托管，已验证 HTTPS 页面访问、时间每秒更新、北京时间显示及浏览器无脚本错误。尚未在真实飞书应用中验证。

托管后，在飞书应用编辑器中进入「添加组件 → 插件 → 更多 → 添加自定义插件」，填写真实 HTTPS 网页地址并预览。若目标飞书环境要求额外的宿主初始化或配置保存，需要依据该入口的开发文档补齐适配。普通网页打开成功不等同于飞书插件接入成功。

公开托管前须获得所有者同意；本地文件路径不能作为供他人访问的插件服务地址。
